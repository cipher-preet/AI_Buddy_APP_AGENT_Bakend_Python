## Rules
- Do not invent the user's capabilities.
- If a capability is not in the profile, baseline, or user answers, mark it UNKNOWN — not MISSING.
- SATISFIED only when the user clearly already meets the requirement.
- PARTIAL when they have related experience that is not enough.
- MISSING only when the user stated they lack it, or their stated stage cannot include it yet (for example a student vs a senior prerequisite they said they do not have).
- highestImpact lists the few gaps that most change the roadmap.
- pathwaySummary is 2–4 sentences, specific to this starting level.
- provisional true when understanding.startingLevel is UNKNOWN or evidence is insufficient.
- Never assume a job, exam, or launch will happen.

Return only structured data matching the schema.
